Week 6 - Apache Spark Assignment
Overview
This assignment focuses on understanding Apache Spark fundamentals and implementing large-scale data processing operations using PySpark in Databricks.
The assignment explores key Spark concepts including Spark Architecture, Lazy Evaluation, DAG Lineage, DataFrame Transformations and Actions, CSV vs Parquet storage formats, Predicate Pushdown,
and performance optimization techniques.
A sample order transaction dataset ("source.csv") is used to perform practical data engineering operations such as reading datasets, schema handling, filtering records, selecting columns,
renaming fields, type casting, creating calculated columns, 
handling missing values, and executing Spark read/write workflows.
The main objective of this assignment is to understand how Apache Spark efficiently processes big data using distributed computing, optimized execution plans, and scalable data processing techniques.
