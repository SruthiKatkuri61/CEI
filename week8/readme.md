# E-Commerce Order Analytics System

## Overview
This project is developed as part of the Celebal Technologies Internship.

## Features

### Part 1 - Data Generation
- Generated Customers
- Generated Products
- Generated Orders
- Generated Order Items

### Part 2 - Data Cleaning
- Email validation
- Product cleaning
- Missing value handling
- Duplicate checking

### Part 3 - SQL Analysis
- Basic SQL Queries
- Intermediate SQL Queries
- Advanced SQL Queries

### Part 4 - Python + SQL Integration
- User selects report type
- Date range input
- Summary Report
- Revenue Analysis
- Top Products
- Previous Period Comparison

### Part 5 - Edge Case Testing
- Invalid Order IDs
- Invalid Discount (>100)
- Quantity = 0
- Future Order Dates

## Technologies Used
- Python
- Pandas
- SQLite
